# 肝母细胞瘤家长科普问答小程序（RAG）— 导师汇报提纲

> 用途：向导师（上海儿童医学中心肿瘤外科）汇报项目构想与已完成的原型，争取科室主体授权与知识库审核支持。
> 铁律：不向家长端暴露具体医院名称；仅做科普问答，不做诊断 / 不开方 / 不给剂量。

## 一、一句话定位
做一个嵌在微信里的"肝母细胞瘤家长问答"小程序：家长用大白话提问，系统基于**科室审核过的科普知识库**用 AI 生成回答，答案强制标出处、检索不到就拒答——把"编瞎话"的概率压到最低。

## 二、为什么做（临床痛点）
- 肝母细胞瘤家长信息焦虑重，网上伪科普多、真假难辨，容易被带偏治疗决策。
- 门诊时间有限，大量基础重复问题消耗医生精力。
- 通用大模型在专科知识上容易幻觉、给错建议，直接给家长用有医疗风险。

## 三、已经做到哪（已搭好、可现场演示的原型）
- 前端微信小程序（问答 / 历史 / 须知三页）+ 后端 RAG 管线，代码已在本地就绪。
- **控幻觉四道防线**：① 检索优先；② 严格提示词（仅依知识库、强制 `[来源N]` 引用、无内容必拒答）；③ 置信度门控（检索相似度不够直接拒答，根本不调模型）；④ 答案回传来源可追溯。
- 大模型 / 向量库可插拔，开发者改配置即可换模型，不碰业务代码。

## 四、合规与风险（主动兜住，让科室放心）
- **主体**：以科室机构资质注册小程序，规避个人号无法过医疗类目审核的限制。
- **不暴露医院**：家长端 UI / 文案不出现具体医院名称，保护科室品牌、避免不必要的责任绑定。
- **边界**：明确只做科普问答，不给诊断、不开方、不给剂量；显著免责声明 + 引导线下就医。
- **内容安全**：知识库上线前须高年资医生审核；用户提问走微信内容安全接口。
- **隐私**：对话数据加密存储，符合《个人信息保护法》（PIPL）。

## 五、对导师与科室的价值
- 患者教育工具：提升家长依从性、降低重复咨询、改善随访体验。
- 科普品牌沉淀：与现有「肝芽守护」科普号协同，形成科室可复用的科普资产。
- 潜在科研产出：脱敏后的问答数据可支撑"患儿家庭信息需求"类真实世界研究。
- 学生训练：全栈 + AI 工程能力落地，产出可写入培养档案。

## 六、需要导师拍板 / 支持（三件事）
1. 是否同意以**科室名义**注册小程序主体（提供机构资质）。
2. 指定一位高年资医生负责知识库终审。
3. 是否需走医院**伦理审查**（建议先确认，涉及健康相关 AI 工具）。

## 七、本周可推进
- 用公众号已有科普结构化知识库，跑通 demo。
- 后端上**微信云开发**（免运维、天然 HTTPS），快速出可演示版本。
- 起草免责声明与隐私政策，预约伦理 / 合规咨询。

> 汇报建议：带一台能演示的手机 / 录屏，开场先让导师亲手问一个问题看效果，再讲架构和风控——比纯 PPT 有说服力。
